آوانویس ۱.۵ — به‌روزرسانی رابط و عیب‌یابی میکروفون

تغییرات:
- چهار رنگ مینیمال (آبی، بنفش، سبز، مرجانی) و حالت روشن/تاریک؛ ذخیره در DataStore.
- داشبورد جدید با کارت آغاز مطالعه، آمار دفترها و جلسه‌ها و کارت‌های مرور.
- نمایش بهتر خروجی‌ها در ردیف افقی قابل پیمایش.
- تنظیمات قابل پیمایش شامل رنگ، حالت تاریک، روشن ماندن صفحه، مکث، فونت و سایر گزینه‌های پیشین.
- تشخیص خطاهای میکروفون، نبود سرویس گفتار، مشکل شبکه و نبود زبان فارسی.
- محدود کردن تلاش‌های ناموفق راه‌اندازی و راهنمای عیب‌یابی/تنظیمات مجوز برنامه.
- حفظ شناسه بسته، پایگاه داده Room، نام کلیدهای تنظیمات قدیمی و همه امکانات قبلی.

نکات مهم:
- ساخت و اجرای واقعی Android APK در این محیط قابل انجام نبود. سورس باید در GitHub Actions کامپایل و روی گوشی تست شود.
- SpeechRecognizer اندروید به سرویس تشخیص گفتار نصب‌شده روی گوشی وابسته است؛ صرف اصلاح کد تضمین نمی‌کند مشکل میکروفون هر گوشی حل شود.
- برای حفظ یادداشت‌ها، برنامه قبلی را حذف نکنید؛ APK جدید را با امضای یکسان روی نسخه فعلی نصب کنید.
- نسخه جدید: versionCode=5 و versionName=1.5.0

نصب به‌روزرسانی از Termux (فایل PATCH را دانلود کنید):
cd "$HOME/avanevis3/AvaNevis_Android_Project"
unzip -o "$HOME/storage/downloads/AvaNevis3_v1.5_Update_Patch.zip"
git add app
git commit -m "Update AvaNevis to v1.5 UI and speech diagnostics"
git push origin main

پس از موفقیت build، در GitHub Actions > آخرین اجرای سبز > Artifacts فایل APK را دانلود کنید.
