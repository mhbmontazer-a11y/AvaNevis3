# آوانویس ۳.۰ — نسخهٔ تمام‌آنلاین (سورس مستقل)

- ورودی میکروفون: AudioRecord با نرخ ۱۶kHz PCM mono
- ارسال قطعات ۸ ثانیه‌ای WAV به سرور HTTPS با رمز دسترسی شخصی
- سرور: FastAPI و درگاه API تبدیل گفتار فارسی؛ کلید ارائه‌دهنده فقط روی سرور
- ذخیرهٔ نتایج در دفترها و استفاده از رابط کاربری موجود
- بدون وابستگی به Google Voice Typing، Vosk، کتابخانهٔ بومی Whisper یا مدل‌های حجیم در APK
- نسخهٔ فعلی متن زندهٔ کلمه‌به‌کلمه ندارد و به سرور آنلاین و اینترنت نیاز دارد.

## نصب
سورس را در مخزن GitHub قرار دهید. GitHub Actions آزمون و سپس `assembleDebug` را اجرا می‌کند. APK تنها در صورت سبزشدن ساخت در Artifacts ظاهر می‌شود. سپس سرور را مطابق `online-server/README_FA.md` راه‌اندازی و نشانی HTTPS و رمز آن را در تنظیمات برنامه وارد کنید.

**وضعیت اعتبارسنجی:** این پروژه در محیط حاضر کامپایل کامل نشده و APK آزمایش‌شده نیست. کد سرور نمونهٔ عملی برای راه‌اندازی شخصی است؛ برای استفادهٔ عمومی باید امنیت و مقیاس‌پذیری آن تقویت شود.
