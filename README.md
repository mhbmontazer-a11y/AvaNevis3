# آوانویس هوشمند مطالعه (AvaNevis Study) — اپلیکیشن اندروید یادداشت‌برداری صوتی فارسی

اپلیکیشن نیتیو اندروید (Kotlin + Jetpack Compose + Room + Foreground Service) برای یادداشت‌برداری صوتی هوشمند و بدون دخالت دست هنگام مطالعه کتاب، مقاله و جزوه.

## اصلاحات نسخه ۱.۲ (حفظ واژه‌ها و پایداری جلسه)

- **متن موقت فقط یک پیش‌نمایش است**: `onPartialResults` دیگر هیچ یادداشت جدیدی وارد Room نمی‌کند. پیش‌نمایش درجا تغییر می‌کند؛ فقط متن نهایی پس از سکوت انتخاب‌شده ذخیره می‌شود.
- **ادغام خروجی نشست‌های پشت سر هم**: `UtteranceAccumulator` قسمت‌های هم‌پوشان و بافرهای گسترش‌یابنده را یک عبارت واحد می‌کند؛ مکث کوتاه موجب ساخت یادداشت‌های «سلام» / «سلام حالت» / «سلام حالت چطوره» نمی‌شود.
- **تفکیک مهلت آماده‌شدن از ذخیره متن**: هیچ تایمری متن ناقص را به‌زور ذخیره نمی‌کند. یک مهلت جداگانه فقط وقتی سرویس پیش از آماده‌شدن پاسخ نمی‌دهد، آن را بازیابی می‌کند.
- **شروع سریع‌تر**: تنظیمات جاری از UI به سرویس فرستاده می‌شود تا شروع میکروفون منتظر خواندن DataStore نماند. وضعیت «آماده» فقط بعد از رویداد `onReadyForSpeech` نشان داده می‌شود.
- **مکث قابل‌تنظیم**: مقدار پیش‌فرض ۳۵۰۰ میلی‌ثانیه است (قابل تنظیم از ۱۵۰۰ تا ۸۰۰۰). اگر حین یک جمله مکث طولانی دارید، مقدار را بیشتر کنید.
- **ذخیرهٔ ایمن هنگام توقف**: پیش از خاتمهٔ سرویس، ذخیره‌های معلق پایگاه داده تکمیل می‌شوند.
- **اصلاح رشته‌های Regex در Kotlin** و اضافه‌شدن تست‌های رفتار بافر موقت و ادغام گفتار.

- **حفظ تکرارهای معنادار**: پردازش متن دیگر واژه‌های تکراری مثل «نه نه» یا «خیلی خیلی» را خودکار حذف نمی‌کند.
- **حفظ نویسهٔ «ئ»**: اصلاح نرمال‌سازی‌ای که واژه‌هایی مثل «مسئله» را خراب می‌کرد.
- **اصلاح شمارش یادداشت‌ها و پایان جلسه**: ذخیره هر جمله دیگر جلسه را اشتباهاً پایان‌یافته علامت نمی‌زند؛ شمارش یادداشت‌ها بعد از حذف نیز به‌روز می‌شود.
- **اصلاح بازگشت به صفحه اصلی** و همگام‌سازی جلسه‌ای که با فرمان صوتی ساخته می‌شود.
- **بازیابی سرویس تشخیص گیرکرده**: اگر سرویس پیش از آماده‌شدن پاسخ ندهد، پس از مهلت مشخص دوباره تلاش می‌شود؛ این زمان‌سنج هرگز متن را به اجبار ذخیره یا هنگام گفتار قطع نمی‌کند.
- **شفاف‌سازی حالت آفلاین**: برنامه فقط از سرویس تشخیص گفتار نصب‌شده در اندروید استفاده می‌کند و «ترجیح آفلاین» تضمین نمی‌کند که پردازش واقعاً آفلاین باشد.


**محدودیت مهم:** `android.speech.SpeechRecognizer` یک API مبتنی بر نشست است و ضبط واقعاً بدون فاصله، حفظ کامل کلمات قبل از `onReadyForSpeech` یا پذیرش یکسان تنظیمات سکوت توسط همهٔ گوشی‌ها را تضمین نمی‌کند. این نسخه با حذف تأخیرهای قابل‌کنترل برنامه و انتظار برای نتیجهٔ نهایی هنگام توقف، احتمال جاافتادن متن را کاهش می‌دهد، اما برای ضبط کاملاً پیوسته و تضمین کلمات اول باید از موتور ASR جریانی با دریافت مداوم PCM و بافر پیش‌ازگفتار (مانند یک پیاده‌سازی مبتنی بر Whisper با مدل فارسی مناسب) استفاده شود. برای آزمون، **پس از نمایش «میکروفون آماده»** صحبت کنید.

## ویژگی‌های کلیدی معماری
1. **شنیدن خودکار با نشست‌های پیاپی (`ContinuousSpeechEngine`)**: فقط یک بار دکمه «شروع مطالعه» را لمس می‌کنید؛ پس از خواندن هر عبارت و گذشت مکث تنظیم‌شده، متن به‌صورت خودکار در خط جدید ذخیره شده و موتور بدون نیاز به لمس صفحه آماده جمله بعدی می‌شود.
2. **پردازشگر تخصصی زبان فارسی (`PersianTextProcessor`)**: یکسان‌سازی «ی» و «ک» فارسی، درج هوشمند نیم‌فاصله (`می‌شود`، `روش‌های`، `مؤثرترین`، `بلندمدت`، `فاصله‌دار`)، تشخیص خودکار جملات پرسشی (`؟`) و خبری (`.`)، تبدیل ارقام به فارسی/لاتین و کاهش تکرارهای ناشی از بافر موقت و نهایی موتور گفتار.
3. **اجرا با صفحه خاموش و در پس‌زمینه (`StudyListeningService`)**: پیاده‌سازی استاندارد `ForegroundService` از نوع `microphone` به همراه `PARTIAL_WAKE_LOCK` و مدیریت تماس تلفنی (`AudioFocusRequest`).
4. **مدیریت دفاتر مطالعه، جست‌وجوی فارسی و خروجی `TXT` / `PDF` راست‌به‌چپ (`ExportManager`)**.

## روش‌های دریافت سریع فایل نصبی `.apk`

### روش اول: ساخت خودکار ابری با GitHub Actions (بدون نیاز به نصب Android Studio)
این پروژه دارای فایل `.github/workflows/build-apk.yml` است:
1. یک مخزن (Repository) جدید در GitHub بسازید و فایل‌های این پروژه را در آن آپلود کنید.
2. به تب **Actions** در مخزن گیت‌هاب بروید و جریان کاری **Build AvaNevis Android APK** را اجرا کنید (یا پس از push به `main` / `master` منتظر اجرای خودکار بمانید).
3. پس از موفقیت ساخت و تست‌ها، فایل `AvaNevis-Study-Debug-APK` در بخش **Artifacts** قرار می‌گیرد. زمان ساخت به صف و سرعت GitHub Actions بستگی دارد.

### روش دوم: ساخت در Android Studio روی کامپیوتر شخصی
1. پروژه را در Android Studio (نسخه Iguana یا جدیدتر با JDK 17) باز کنید.
2. از منوی بالا گزینه **Build > Build Bundle(s) / APK(s) > Build APK(s)** را انتخاب کنید.
3. فایل نصبی در مسیر `app/build/outputs/apk/debug/app-debug.apk` تولید می‌شود.
