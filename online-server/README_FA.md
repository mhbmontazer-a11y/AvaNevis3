# سرور آوانویس آنلاین

برای استفاده، این سرویس را روی یک میزبان دارای HTTPS راه‌اندازی کنید. **APK به‌تنهایی بدون سرور و اعتبار سرویس گفتار نمی‌تواند متن تولید کند.**

```bash
cd online-server
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
export OPENAI_API_KEY='YOUR_PROVIDER_API_KEY'
export AVANEVIS_ACCESS_TOKEN='CHOOSE_A_LONG_RANDOM_SECRET'
uvicorn server:app --host 127.0.0.1 --port 8000
```

برای دسترسی از گوشی، باید یک reverse proxy با HTTPS (مانند Caddy) یا میزبانی HTTPS داشته باشید. در تنظیمات برنامه نشانی پایه مانند `https://asr.example.com` و رمز `AVANEVIS_ACCESS_TOKEN` را وارد کنید. کلید `OPENAI_API_KEY` **فقط** روی سرور است.

این نسخه از مدل `whisper-1` در API برای تبدیل قطعات ۸ ثانیه‌ای استفاده می‌کند؛ بنابراین متن کلمه‌به‌کلمهٔ هم‌زمان ارائه نمی‌دهد. هر قطعه مستقل پردازش می‌شود و ممکن است جمله در مرز قطعات شکسته شود. قطع اینترنت یا خطای سرور به کاربر نمایش داده می‌شود و این نسخه هنوز صف ارسال مجدد مطمئن ندارد. برای ضبط محرمانه از سرویس آنلاین استفاده نکنید مگر با اطلاع و رضایت لازم.

در محیط واقعی، rate limiting، پایش هزینه، محدودیت درخواست، و محافظت از سرور لازم است. سرور نباید بدون احراز هویت در اینترنت عمومی منتشر شود.
